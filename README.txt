ANSUM SANAL - STUDENT PORTFOLIO
Web Development Lab (HTML, CSS, JavaScript)

PURPOSE
A personal portfolio site that presents my C programs and my Git/GitHub lab work.
It was built from the provided HTML demonstration page, which I studied and then
rewrote into a themed, multi-section website.

PAGES AND SECTIONS (single page, in-page navigation)
- Header with a drawing-style "title block" of quick facts
- About, Skills, Projects (with a table), Gallery (with a filter), Contact (form)

FEATURES
- Responsive layout: works on phone and desktop widths
- Light / dark theme toggle (choice is remembered in the browser)
- Gallery filter by type (All, Repository, History, Documentation)
- Contact form with validation and clear error messages
- Accessibility: skip link, semantic elements, labelled form controls, image alt text,
  visible keyboard focus, reduced-motion support

CONTACT FORM (IMPORTANT)
The form is a FRONT-END DEMONSTRATION only. JavaScript checks the input in the browser,
but nothing is sent or stored. There is no backend and no database.

HOW TO RUN
1. Keep the folder structure as it is.
2. Double-click index.html (or right-click > Open with > your browser).
   No installation or server is needed. An internet connection is only used to load the
   Google Fonts; if offline, the page uses fallback fonts and works the same.
