About me

I'm a first-year B.Tech student in the AI EEE branch. This site collects what I have built so far: console programs in C and a project repository where I practised Git and GitHub.

I'm early in my course, so most of my work is practice projects. What matters to me is that each one runs, is documented, and has a clear history of how it changed.

How I work on a project

  1. Write or change a small piece of code.
  2. Check what changed with git status.
  3. Commit it with a message that says what changed.
  4. Try bigger changes on a separate branch.
  5. Merge the branch and push to GitHub.
About this site: I built it for the Web Development Lab using plain HTML, CSS and JavaScript. There is no backend, so the contact form only demonstrates validation and does not send messages.

Skills

  • C programming: console programs that take input, calculate and print results (calculator.c, student_record.c).
  • Git and GitHub: commits, branches, merges, resolving a merge conflict and pushing to a remote repository.
  • Command line: using PowerShell to run Git commands and compile with gcc.
  • HTML, CSS and JavaScript: still learning; this site is my first result.
